AoM:EE Visual Model Comparison Benchmark
=========================================

Purpose:
  Temporary human-visual comparison of SR models.

Selected source images are stored under:
  original\

Before running any AI model, inspect:
  selection\original_review\

Manifest:
  visual_model_comparison_manifest.csv

Selection targets:
  40 Icons
  25 UI
  10 Portrait/Artwork
   5 Effect/Misc

The original source textures are copied without modification.
No upscaling is performed by this preparation script.
